# Tutorials

The tutorials solve complete problems from start to finish, the way they come
up in a course or a tutoring session. Each one uses several functions
together and explains the chemistry along the way.

<div class="grid cards" markdown>

-   :material-account-school:{ .lg .middle } [**A tutoring session**](tutoring-session.md)

    ---

    Check a student's work on a three-part ammonium nitrate problem and find
    where it went wrong.

-   :material-flask-outline:{ .lg .middle } [**Preparing solutions**](solutions.md)

    ---

    Weigh out a solute for a target concentration, check a solution's
    molarity, dilute a stock solution, and work a titration.

-   :material-weather-windy:{ .lg .middle } [**Gas law problems**](gases.md)

    ---

    Molar volume, tank pressure from a mass of gas, mass from P, V and T, and
    identifying an unknown gas.

</div>

All three assume you have read the
[Quickstart](../getting-started/quickstart.md). For short, copy-and-paste
answers to single questions, see the [Cookbook](../cookbook.md).
