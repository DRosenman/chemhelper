    About the masses

    Masses are the rounded values found on most classroom periodic tables, usually two decimal places. Elements with no stable isotope (Tc, Pm, and Po through Ac) use the mass number of a long-lived isotope. Elements beyond uranium are not included yet; see the roadmap.

    Get this data in Python¶

    from chemhelper import elements

elements.Fe.mass                 # one element
elements.elements["Fe"]          # the same Element, looked up by symbol
elements.element_table           # everything, as a pandas DataFrame

    See the elements guide for everything you can do with it.
