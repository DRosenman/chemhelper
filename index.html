    chemhelper¶

    General chemistry answers in one line of Python,
    and the worked solution in one more.

    Get started User guide API reference

    chemhelper solves the problems that fill the first semester of general chemistry: molar mass, percent composition, converting between grams, moles and molarity, and the ideal gas law. Every solver has a twin whose name ends in _steps that prints the solution the way you would write it on a whiteboard.

    It was written by a chemistry tutor, for tutoring. Check a student's answer in a second, show exactly where it came from, and spend the rest of the session on understanding.

    >>> from chemhelper import compounds
>>> compounds.mass('Ca(OH)2')
74.1

    >>> from chemhelper import compounds
>>> compounds.mass_steps('Ca(OH)2')
Ca(OH)2
Ca: 40.08
O: 2 x 16.0 = 32.0
H: 2 x 1.008 = 2.016

Mass Ca(OH)2 = 40.08 + 32.0 + 2.016 = 74.1

    How many grams of NaCl do you need for 2 L of a 0.5 M solution?

    >>> from chemhelper import conversions
>>> conversions.molarity_to_grams_steps(0.5, 2, 'NaCl')
0.5 moles/L x 2 L = 1 moles
NaCl
Na: 22.99
Cl: 35.45

Mass NaCl = 22.99 + 35.45 = 58.44
1 moles x 58.44 grams/mole = 58.44 grams

    What's inside¶

    • elements

      Symbol, name, atomic number and mass for elements 1 to 92, as objects and as a pandas table.

      Elements guide

    • compounds

      Parse formulas like Al2(SO4)3, then get molar mass, mass composition and percent composition.

      Compounds guide

    • conversions

      Grams to moles and back, molarity from mass or moles, and solute needed for a target concentration.

      Conversions guide

    • ideal_gas

      Solve PV = nRT for any variable, with inputs in atm, torr, mmHg, kPa, L, mL, K or °C.

      Ideal gas guide

    Why use it¶

    • Shows its work

      Every solver has a _steps twin. The printed solution includes units and each intermediate value.

    • Reads like chemistry

      Formulas are written the way they appear in a textbook, parentheses and all. Arguments are named after the quantities.

    • Tells you what went wrong

      A typo in a formula or a missing value raises an error that names the problem, not a cryptic traceback.

    • Tested examples

      Every example on this site is run against the real package before the site is published.
